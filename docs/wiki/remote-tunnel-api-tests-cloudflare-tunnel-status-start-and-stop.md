## Overview

PocketPaw runs locally by default, accessible only on `localhost`. The remote tunnel feature uses `cloudflared` to create a temporary public URL, enabling access from mobile devices or sharing with others without port-forwarding or firewall changes. The remote API manages this tunnel's lifecycle. All operations delegate to `get_tunnel_manager()`, which returns a singleton `TunnelManager`.

## Status (`GET /remote/status`)

`TestTunnelStatus` covers both tunnel states:

- **Inactive**: `{"active": false, "url": null}`. A null URL when inactive is important — the client must not attempt to construct a link from a null value.
- **Active**: `{"active": true, "url": "https://abc.trycloudflare.com"}`. The test asserts `"trycloudflare" in data["url"]` rather than an exact URL match, since the subdomain is randomly generated by Cloudflare.

## Start Tunnel (`POST /remote/start`)

`TestTunnelStart` covers two cases:

- **Success**: `mgr.start()` returns the tunnel URL; the response has `active: true` and the URL. The dashboard uses this URL to display a QR code or clickable link.
- **Failure**: `mgr.start()` raises `RuntimeError("cloudflared not found")`. Rather than returning 500, the route catches the error and returns 200 with `{"active": false, "error": "cloudflared not found"}`. This is intentional — the tunnel is an optional feature, and a missing `cloudflared` binary is a configuration issue, not a server crash. Returning 200 allows the dashboard to display a helpful error message ("Install cloudflared to enable remote access") rather than triggering generic error handling.

```python
def test_start_failure(self, mock_get, client):
    mgr.start = AsyncMock(side_effect=RuntimeError("cloudflared not found"))
    resp = client.post("/api/v1/remote/start")
    assert resp.status_code == 200
    assert "cloudflared" in data["error"]
```

## Stop Tunnel (`POST /remote/stop`)

`TestTunnelStop` confirms that `mgr.stop()` is called exactly once and the response has `active: false`. There is no separate "not running" test — stop is expected to be idempotent (calling it when the tunnel is already stopped should not error).

## Architectural Notes

The async nature of `mgr.start` and `mgr.stop` (patched as `AsyncMock`) reflects that starting a Cloudflare tunnel involves spawning a subprocess and waiting for it to output its URL. FastAPI's `TestClient` handles async route handlers transparently, so the tests do not need `pytest-asyncio`.

The tunnel manager is a singleton accessed via `get_tunnel_manager()` — the same pattern used by the MCP manager, scheduler, and other subsystems. This makes the dependency easy to patch in tests without requiring dependency injection at the route level.
