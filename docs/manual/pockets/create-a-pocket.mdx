# Create a Pocket

**What it is.** Two ways to make a new Pocket: pick a ready-made template, or describe what you want in chat and let Paw OS by PocketPaw build it.

**When you'd use it.** Use a template for a fast, proven starting point. Use chat when you want something specific to your business.

## Create from a template
1. Go to **/pockets**.
2. In the left sidebar under **Quick Create**, click **Templates**. (You can also click the **Create Pocket** card at the end of the grid, or **Browse templates** on an empty workspace.)
3. The **Create a Pocket** window opens with a gallery of templates.
4. Filter with the category pills (**All**, **Business**, **Hospitality**, **Healthcare**, **Legal**, **DevOps**, **Research**, **Custom**) or type in **Search templates**.
5. Hover a template card and click **Use Template**.
6. The Pocket is created and opens on its own page.

To start from nothing, pick the **Blank** template — it creates an empty Pocket you fill in yourself.

## Create with chat
1. Go to **/pockets**.
2. In the left sidebar, click **New Pocket** — or on an empty workspace click **Create with AI**.
3. The chat panel on the right is ready. The box reads "Describe a pocket to create..."
4. Type what you want in plain language, for example: "Build a customer feedback tracker from Slack and email."
5. Press Enter.
6. Paw OS builds the Pocket and opens it. The widgets appear on the canvas.

If you're not sure where to start, the chat panel shows suggestion buttons like **Competitive analysis**, **Sprint dashboard**, **Content calendar**, **Feedback tracker**, and **Cost monitoring**. Click one to drop the prompt in, then edit it before you send.

## Tips
- Be specific in chat. Name the data you want and the widgets you expect ("a chart for revenue, a list of open orders").
- Some templates show an **Install fleet** checkbox. Tick it to add the matching set of helper agents when the Pocket is created.

## If something's off
- If a chat-built Pocket comes back without widgets, your description may have been too vague. Re-describe it with the specific charts or lists you want.
- Templates marked **Blank** create an empty Pocket on purpose — that's expected, not a failure.
