# Edit a Pocket

**What it is.** Once a Pocket is open, you change it by chatting with it or by using the toolbar across the top — layout, sharing, data, and delete all live there.

**When you'd use it.** Use this when you want to add a widget, rearrange the screen, share with a teammate, or remove a Pocket you no longer need.

## Edit with chat
1. Open the Pocket from the grid at **/pockets**.
2. Use the chat panel on the right. The box reads "Edit this pocket..."
3. Type the change you want, for example: "Add a new chart widget to this pocket."
4. Press Enter. The change applies to the canvas you're looking at.

The chat panel offers quick edits under **Edit this pocket**: **Add a widget**, **Rearrange layout**, **Connect data source**, and **Clean up pocket**. Click one to use it as your prompt.

## Change the layout
1. With the Pocket open, click the **Layout** button in the top toolbar.
2. Pick a preset, or choose **Auto** to let Paw OS by PocketPaw arrange widgets based on the content.
3. The canvas re-arranges to match.

## Share a Pocket
1. Open the Pocket.
2. Click the **Settings** button in the toolbar, then **Share & Collaborate** (or open the **Share** view from the toolbar).
3. Add a teammate, or set who can see the Pocket.

## Switch views
The toolbar holds icons for each view of the Pocket: **Widgets**, **Data**, **Files**, **Automations**, **Actions**, **Audit**, **Customer Widget**, **Share**, and **Debug**. Click an icon to switch. **Actions** shows a number badge when items are waiting for your approval.

## Delete a Pocket
1. Open the Pocket.
2. Click the **Settings** button in the toolbar.
3. Click **Delete Pocket**.
4. Click **Delete?** to confirm, or the X to cancel.

## Tips
- Editing in chat updates the live Pocket — there's no separate save step.
- Only the Pocket's owner can change the backend write policy under **Configure Backend** in the Settings menu.

## If something's off
- If a chat edit doesn't appear, make sure you have the right Pocket open — chat edits apply to the open Pocket only.
- Delete is two steps on purpose (**Delete Pocket**, then **Delete?**). If nothing happens, you may have only completed the first step.
- This page is a partial draft. Confirm the Settings menu items, the Layout presets, and the delete confirmation in the running app.
