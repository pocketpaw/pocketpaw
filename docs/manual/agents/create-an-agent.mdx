# Create an agent

**What it is.** A short form that spins up a new agent with just a name, a persona, and a backend. You fill in the rest later.

**When you'd use it.** Use it the first time you need a helper for a job — and any time you want a fresh agent for a new role.

## Create a new agent
1. On the **Agents** screen, click **Create New**.
2. The **New Agent** dialog opens.
3. Type a **Name** (for example, CFO, Content Writer, or Research Bot).
4. In **Persona**, describe who the agent is, what it's good at, and how it should behave. You can leave this blank for now.
5. Pick a **Backend** — the AI provider that powers the agent: Claude (Anthropic), OpenAI, Google (Gemini), or Deep Agents.
6. Click **Create Agent**.

The agent opens in the editor so you can configure the rest.

## Tips
- The name is the only required field. A blank persona gets a sensible default.
- Press Command-Enter to create without reaching for the mouse. Press Escape to cancel.
- As the dialog says: you can configure everything else after creation.

## If something's off
- "Enter a name" means the Name field is empty. Type a name and try again.
- If creation fails, the error appears as a small pop-up message. Check that you're signed in and online, then retry.
- **Import Soul** sits next to **Create New** but isn't wired up yet — clicking it does nothing visible. Use **Create New** instead.
