# What is an agent

**What it is.** An agent is an AI worker you set up once and reuse. You give it a name, a persona, a model, and a set of tools, then chat with it or point it at work.

**When you'd use it.** Use an agent when you want a consistent helper for a recurring job — a CFO that reviews numbers, a content writer, a research bot.

## Open the agents screen
1. Go to **Agents** in Paw OS by PocketPaw.
2. The left panel lists every agent in your workspace.
3. Click any agent card to open it. The right panel shows its settings.
4. If no agent is selected, you'll see "Select an agent" in the right panel.

## Read an agent card
- The colored dot shows status.
- The name and role sit at the top of the card.
- The date on the right is when the agent was last updated.

## Tips
- Each card opens the full editor with tabs for **Profile**, **Knowledge**, **Soul**, **Tools**, **Reasoning**, and **Plugins**.
- Use the search box at the top of the list to filter by name.

## If something's off
- An empty list saying "No agents found" can mean you're signed out, the workspace is offline, or you haven't created an agent yet. Create one with **Create New**.
- The status dot and energy bar on each card are display-only right now. Don't read them as live health signals.
