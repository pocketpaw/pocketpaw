# Welcome to Paw OS by PocketPaw

This is the guide to using Paw OS — how to set up your workspace, work with your agents and team, and run real work end to end. Every page walks one task at a time, in plain steps you can follow in the running app.

New here? Start with the path below. It takes you from a fresh account to your first working setup. After that, jump to whatever you need from the full list.

## Start here

A short path for a brand-new owner. Do these in order and you'll have a working workspace.

1. [Create your account](/manual/getting-started/create-your-account) — sign in and get your workspace ready.
2. [Let Paw OS set up your business](/manual/getting-started/let-paw-os-set-up-your-business) — run the guided setup and install a starter kit.
3. [Your workspace](/manual/workspace-tour/the-tour) — get the lay of the land before you go deeper.
4. [Connect your tools](/manual/connectors-data/connect-your-tools) — link the apps and data you already use.
5. [Create a Pocket](/manual/pockets/create-a-pocket) — build your first focused screen for one job.
6. [Approve or reject actions](/manual/approvals/approve-or-reject-actions) — learn how you stay in control of what your agents do.
