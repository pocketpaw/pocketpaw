# Calendar

**What it is.** The Calendar screen shows your events in **Month**, **Week**, **Day**, or **Agenda** view. You can move through dates, create and edit events, and filter what you see by workspace area.

**When you'd use it.** To plan your week, check what's coming up, or add a new event.

## Switch views and move through dates
1. Open **Calendar** from the left.
2. Use the view switcher to pick **Month**, **Week**, **Day**, or **Agenda**.
3. Use the **‹** and **›** arrows to move to the previous or next period.
4. Click **Today** to jump back to the current date.

## Create an event
1. Click **New event** in the header.
2. In **Month** view, you can also click an empty day to start an event on that day.
3. Fill in the event details and save.

## Edit or remove an event
1. Click an event chip to open its details.
2. Open the editor from there to change the time or details.
3. Save your changes, or remove the event.

## Filter by workspace area
1. Use the filter row above the grid.
2. Click **All** to see everything, or click one of the colored pills to show only that area's events.
3. Click the active pill again to clear the filter.

## Tips
- The count on the right of the filter row tells you how many events are in the current view.
- Each colored dot ties an event to a workspace area, so you can tell at a glance what it belongs to.
- **Agenda** view is the quickest way to see what's scheduled next as a plain list.

## If something's off
- An empty **Agenda** view means nothing is scheduled in that window — try a wider range or clear the filter.
- If events look stale, click the refresh icon in the header.
- Events tied to a workspace area only show when that area's filter (or **All**) is selected.
