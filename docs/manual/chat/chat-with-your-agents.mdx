# Chat with your agents and team

**What it is.** The chat screen is where you talk to your AI agents and your teammates. You type in the box at the bottom, hit send, and the agent replies in the thread. The agent can also build things, run tasks, and pull in files while you chat.

**When you'd use it.** Any time you want to ask an agent to do something, or message a person on your team.

## Send your first message
1. Open **Chat** from the left.
2. The conversation starts on **General** — the default place to talk to your agent.
3. Click the message box at the bottom (it says **Ask anything…**).
4. Type your request and press Enter to send.
5. Watch the reply stream in. A small status line shows what the agent is doing while it works.

## Start a new chat
1. Click the **+** icon at the top of the sidebar (it says **New message**).
2. Pick a teammate or an agent to message.
3. Or, inside an agent conversation, open the agent and click **New chat** to start a fresh thread without losing the old one.

## Mention people, agents, files, and channels
1. In the message box, type **@**.
2. A list pops up grouped by **Members**, **Agents**, **Files**, and **Channels**.
3. Keep typing to filter, then click the one you want.
4. The mention is added to your message. Use it to point the agent at a specific file or loop in a teammate.

## Run a slash command
1. Type **/** at the very start of an empty message box.
2. A **Slash commands** list appears with each command and a short description.
3. Pick one with the arrow keys or a click.

## Tips
- Press Enter to send. Your draft is saved if you switch away and come back.
- The agent reply streams in live — you don't have to wait for the whole thing to start reading.
- Use **@** to attach a file the agent should look at, instead of describing it in words.

## If something's off
- If the agent doesn't reply, check that you're signed in — the screen shows a sign-in prompt when your session has dropped.
- The slash list only opens when **/** is the first thing in the box. If you've typed other text first, clear the box and start with **/**.
- Each agent keeps its own separate chats. If you can't find an old conversation, open that agent and look through its thread list.
