# Files

**What it is.** Files is the place to browse, upload, and organize everything in your workspace — files you shared in chat, files on your own device, and connected sources — all in one list.

**When you'd use it.** When you need to find a document, upload something, make a folder, or pull a file into a conversation.

## Browse your files
1. Open **Files**.
2. Use the left sidebar to filter by source:
   - **All** — everything together.
   - **Chat uploads** — files shared in conversations.
   - **Knowledge** — saved knowledge articles.
   - **Local** — files on your own device.
   - **Drive** — connected cloud storage.
3. Switch the view with the layout buttons in the toolbar (grid, list, column, gallery).
4. Narrow the list with the **Filter files…** search box, the type chips (Images, Docs, PDFs, Audio, Video, Other), and the **Sort** menu.

## Upload a file
1. Click the upload button in the toolbar, or drag a file straight onto the list.
2. Pick one or more files.
3. Watch the progress; uploaded files appear in the list.
4. Large files ask you to confirm before they upload.

## Organize with folders
1. Click the new-folder button in the toolbar.
2. Type a name and confirm.
3. To rename a file or folder, use the rename (pencil) action on its row.
4. To delete a folder, use the delete (trash) action on its row and confirm.

## Pull a file into chat
1. Turn on the files chat with the **Chat with files** toggle in the toolbar (or press Ctrl+Shift+K).
2. On a file's row, use the **Add to chat** action to bring it into the conversation.

## Tips
- Folders live under **Chat uploads** (your uploaded files). If you make a folder from **All**, the view switches there so you can see it.
- Selecting a file opens a preview on the right; use it to confirm you've got the right one before downloading.
- Sorting by **Date** groups files into Today, Yesterday, This Week, and Older.

## If something's off
- If **Drive** shows nothing, the cloud connector isn't set up yet — an admin needs to connect it.
- Local files come from your own device, so they appear only when you're using the desktop app.
- A warning banner (for example, "Google Drive isn't connected yet") is informational; dismiss it with the X.
