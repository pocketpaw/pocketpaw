# Quick Ask

**What it is.** Quick Ask is a small floating box you can pop up over anything on your screen, type a question, and send it without opening the full app. The placeholder reads "What can I help with?".

**When you'd use it.** When you want to ask Paw OS by PocketPaw something fast while you're working in another window.

## Ask a quick question
1. Open Quick Ask (it appears as a floating box over your screen).
2. Type your request in the box.
3. Press Enter to send it.
4. Press Esc to close the box without sending.

## What happens after you send
- Your message is handed off to the side panel, where the answer continues.
- The box clears itself each time it opens, so you always start fresh.

## Tips
- Quick Ask is text-only. It's built for a quick question, not for attaching files — use the full Chat area when you need to share a file.
- It supports the same typing helpers as the main chat, including mentions and slash commands.

## If something's off
- Quick Ask is part of the desktop app. If you're using Paw OS in a browser, this floating box may not appear.
- If Enter doesn't send, make sure your cursor is inside the typing box.
