# Generate images and video

**What it is.** Studio turns a written description into an image or a short video. You type what you want into the chat panel on the right, and the results appear in the gallery on the left.

**When you'd use it.** When you need a quick visual — a poster, an illustration, a product clip — without opening a separate design tool.

## Generate your first image or video
1. Open **Studio** from the top navigation.
2. Look at the right-hand panel. The box at the bottom reads "Describe an image or video to generate…".
3. Type a description. Be specific about the subject, the style, and the mood. Example: "A watercolor illustration of a quiet seaside village at dawn, soft pastel washes, loose brushwork."
4. To create a video instead of an image, say so in your description — for example, "A 5-second product video of a smartwatch rotating on a soft-lit pedestal."
5. Send the message.
6. Wait while the gallery shows a loading shimmer. When generation finishes, your result appears in the gallery on the left.

## Use a starter prompt
1. Before you've typed anything, the right panel shows a few suggestion chips, each labeled with what it makes — for example "A cinematic movie poster · image" or "A 5-second product video · video".
2. Click one. It drops the full description into the message box.
3. Edit the wording to match what you actually want.
4. Send the message.

## Add more to the same gallery
1. After your first result lands, keep describing in the same chat panel.
2. Each new request adds to the gallery on the left rather than replacing it.

## Start over
1. Use the new-session control in the chat panel.
2. This clears the chat history and empties the gallery, so you start with a clean canvas.

## Tips
- The more detail you give — subject, lighting, style, color, mood — the closer the result. Vague prompts give vague pictures.
- Say "image" or "video" plainly in your description so the right kind of media gets made.
- Before any result exists, the gallery reads "Nothing generated yet." That's expected — it fills in once your first generation finishes.

## If something's off
- Studio describes-to-create through the chat panel. There is no upload button or fill-in-the-blanks form. If you're looking for one, you're in the right place — just type what you want.
- If generation never completes or returns an error, image and video generation relies on a media provider being set up for your workspace. Ask your workspace admin to confirm that's configured. (See notes — this part could not be verified from the source.)
- A result shows up in the left gallery, not inline in the chat. If the chat looks like it finished but you see nothing, check the gallery panel on the left.
