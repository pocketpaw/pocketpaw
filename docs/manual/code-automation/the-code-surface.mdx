# The Code surface

**What it is.** Code is a built-in editor with an assistant beside it. You see your project files on the left and an edit panel in the middle. You describe what you want in plain words on the right, and the assistant builds, edits, and runs the files for you.

**When you'd use it.** Use it when you want a small script written, an existing file changed, or a piece of code run — without leaving Paw OS by PocketPaw.

## Open Code and look around
1. Go to **Code** in Paw OS. You land on a composer: describe the project you want, pick a framework (or leave it on **Auto**), and press Enter to create it. Existing projects live under **Projects**.
2. Open a project. The project screen has three parts.
3. **Explorer** (left) lists your project files. Click a folder to open it. Click a file to open it in the editor.
4. The middle panel is the editor, with a tab for each file you've opened.
5. The right panel is the chat, where you tell the assistant what to do.

## Ask the assistant to build, edit, or run
1. Click into the box that reads **"Describe what to build, edit, or run…"**.
2. Type what you want in plain language. For example: "Create a script that reads a CSV of sales and prints the total revenue per month."
3. Press Enter. The assistant works directly in your files.
4. Watch the green strip under the editor — it shows what the assistant is doing right now. The full step-by-step output appears in the chat on the right.
5. When the assistant finishes, the file list and any open file refresh on their own to show the changes.

## Edit a file yourself
1. Open a file from the **Explorer**.
2. Type your changes in the editor.
3. Save with **Ctrl-S** (or **Cmd-S** on a Mac).

## Start fresh
- Use the new-session control in the chat panel to start a clean conversation. Your open files stay open.

## Tips
- If you don't know where to start, use the suggested prompts in the empty chat: **Scaffold a small script**, **Edit the open file**, or **Run it and show the output**. Clicking one fills the box — you still press Enter to send.
- To work on a file with the assistant, open it first so it has the file in front of it.
- The assistant and the editor share the same files. A change the assistant makes shows up in the editor, and a change you save shows up to the assistant.

## If something's off
- There is no "new file" or "delete" button in the Explorer. To create or remove a file, ask the assistant in the chat — it does the file work for you.
- The strip under the editor is a status line, not a terminal. Look for the assistant's full command output in the chat panel, not under the editor.
- If your changes vanish, check that you saved (Ctrl/Cmd-S). The auto-refresh after the assistant finishes never overwrites a file you're still editing, but unsaved edits aren't shared with the assistant.
- This surface needs the Paw OS backend running to read and write files. If the file tree stays empty or edits don't save, the connection is the first thing to check.
